# Claude host adaptation

Claude Code can load this plugin through `.claude-plugin/plugin.json` and the skill at the plugin root. Image generation is not required for the workflow.

When no image-generation tool exists:

1. Use user-supplied local assets first.
2. Inspect and qualify user-authorized references when available.
3. Compose direction studies in HTML/CSS and inspect browser screenshots.
4. Use typography, layout, color, crop, material, and interaction to carry art direction.
5. Use CSS for functional geometry and Canvas for genuinely procedural behavior.
6. Record missing photography or illustration as `acquisition-needed` with an exact role, crop, dimensions, and rights requirement.
7. If helpful, write an external image brief, but do not claim the image was generated.
8. Continue implementation without inserting a fake decorative substitute.

Do not block direction approval on generated whole-page mockups. A browser-composed direction prototype, approved reference relationship map, or existing-system evidence can establish direction.

Rendered video is optional. If Remotion is not available, implement meaningful browser motion and specify a static poster/fallback without pretending a video exists.
