# Sponsor Design Lagann

Design Lagann is independent open-source work. Sponsorship gives the project more time for the parts that are easy to promise and difficult to maintain: cross-host compatibility, reference research, accessibility proof, motion quality, deterministic tests, documentation, and clean releases.

## What sponsorship supports

- reliable Codex, Claude Code, and Cursor installation paths;
- stronger reference acquisition without copying other brands;
- better motion choreography and reduced-motion behavior;
- responsive and accessibility verification;
- public fixtures, regression coverage, and release maintenance;
- clear documentation for contributors and new users.

Sponsorship does not buy hidden access, design-score manipulation, or control over the open-source roadmap. Public quality and safety constraints remain the same for everyone.

## Sponsor button status

The repository funding configuration is prepared but intentionally inactive until the official GitHub Sponsors account exists. This avoids sending users to a placeholder or unverified identity.

When the account is approved, edit [`.github/FUNDING.yml`](.github/FUNDING.yml) and uncomment:

```yaml
github: [your-github-sponsors-handle]
```

Then enable **Settings → General → Features → Sponsorships** for the repository. The README already includes the sponsor narrative, so no redesign is required after activation.

## Public recognition

After sponsorship launches, this page can recognize public sponsors in three restrained groups:

- **Core** — sustained maintenance support;
- **Direction** — meaningful recurring project support;
- **Signal** — one-time or entry-level support.

Private sponsors remain private. Recognition will never be disguised as product endorsement.
